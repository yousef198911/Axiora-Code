# Axiora Code

Axiora Code is a source-code editor built on top of the open-source Code - OSS project.

Based on Code - OSS (MIT License) by Microsoft — https://github.com/microsoft/vscode

## Building and running

```bash
npm install
npm run compile
./scripts/code.sh
```

See `product.json` for the product identity (name, application name, data folder).
