# Axiora-Code

Axiora-Code is a code editor built from the open-source [Code - OSS](https://github.com/microsoft/vscode) project using the [VSCodium](https://github.com/VSCodium/vscodium) build scripts (MIT licensed).

- Extensions marketplace: Open VSX
- Built-in themes: Axiora Dark (default), Axiora Light
- Display language: English / العربية (setting `axiora.language`)
- Windows x64 installers are built by `.github/workflows/axiora-windows.yml`.
